# جمع الشهادات (Testimonials)

القسم يظهر في الصفحة الرئيسية **فقط** إذا أُضيفت شهادة واحدة على الأقل في `src/data/content.ar.ts` داخل المصفوفة `testimonials`.

## الشروط
- لا تكتبي أسماء أو قصصًا مخترعة.
- احصلي على **إذن خطي** (رسالة واتساب أو إيميل) قبل النشر.
- انشري الاسم الأول والمدينة فقط، إلا إذا وافقت الأم على أكثر من ذلك.
- لا تضمّني تفاصيل طبية دقيقة أو نتائج استبيان.

## الشكل
```ts
{
  name: "سارة",
  city: "رام الله",
  quote: "نص قصير بكلمات الأم.",
  photo: "" // اختياري
}
```
